# 一方通行的一站式动作参考

这是软件发行与下载仓库，提供版本说明、安装器和桌面软件自动更新文件。

## 下载与更新

- 已安装软件：打开「设置 → 关于 → 软件更新」，检查新版本并下载。软件自动处理分片、断点续传和完整性校验。
- 初次安装：使用对应版本的完整 Windows x64 安装器。
- 程序与本地引擎分别更新；模型权重通过软件内的模型管理功能维护。
- 下载失败时可以稍后继续，不必重新下载已完成的分片。
